# 🛒 E-Commerce Learning Project

A Spring Boot E-Commerce application built from scratch while learning Spring Boot concepts step by step.

## 📖 About This Project

This project is being developed as a learning journey to understand Spring Boot by building a real-world E-Commerce application.

Instead of following tutorials blindly, each feature is implemented incrementally while learning the underlying concepts.

Current technologies:

* Java 21
* Spring Boot 3.5.x
* Maven
* Thymeleaf
* HTML5
* CSS3

---

## 🎯 Learning Goals

The goal of this project is to learn:

* Spring Boot Fundamentals
* Spring MVC
* Thymeleaf
* Dependency Injection
* Services & Repositories
* Spring Data JPA
* MySQL
* Spring Security
* REST APIs
* Exception Handling
* Testing
* Project Structure & Best Practices

## 🛠 Running the Project

### Clone the Repository

```bash
git clone <repository-url>
```

### Navigate to Project

```bash
cd E-commerce
```

### Run Application

```bash
mvn spring-boot:run
```

Application will start on:

```text
http://localhost:8080
```
